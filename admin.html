Connect this device

This page saves clips straight into your GitHub repository, so it needs a key from GitHub. You only do this once per device.

  1. Open GitHub → New token. The name and the public_repo box are already filled in.
  2. Set Expiration to No expiration.
  3. Scroll down, click Generate token, copy it and paste it below.
